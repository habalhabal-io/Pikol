Core USA Pickleball Quick Rules

  • Two-Bounce Rule: The serve must bounce before return; return must bounce before third shot.
  • Non-Volley Zone (NVZ): You cannot hit the ball in the air while standing in or touching the kitchen line.
  • Side-Out Scoring: Points are only scored when your team is serving (unless playing rally format).
  • Start at 0-0-2: Opening serving team gets only one server before side-out.

App Store & Google Play Readiness

Step-by-step export for Apple App Store (iOS) & Google Play Store (Android)

Terminal Commands (Xcode & Android Studio) 
# 1. Create project folder and initialize
mkdir pikol-app && cd pikol-app
npm init -y

# 2. Install Capacitor Core & CLI
npm install @capacitor/core @capacitor/cli @capacitor/ios @capacitor/android

# 3. Initialize Pikol configuration
npx cap init "Pikol" "com.pikol.scorer" --web-dir "."

# 4. Copy this index.html into the folder
# (Click "Download Standalone HTML" below and save it as index.html)

# 5. Add iOS (Apple App Store) and Android (Google Play)
npx cap add ios
npx cap add android

# 6. Open in Xcode (Mac) or Android Studio
npx cap open ios
npx cap open android

1-Click Store Packaging via PWABuilder.com

PWABuilder is Microsoft's free open-source tool that wraps this web app directly into ready-to-upload Apple App Store (.ipa) and Google Play Store (.aab) packages.

  1. Host this single index.html on GitHub Pages, Netlify, or Vercel (free in 2 minutes).
  2. Go to PWABuilder.com and paste your URL.
  3. Click Package for Stores.
  4. Select iOS (App Store) or Android (Google Play) to generate your signed store submission package.

Privacy Policy & Local Storage

Pikol Pickleball Companion is designed with a strict privacy-first and offline-first architecture:

  • No Tracking: Pikol does not track user location, device identifiers, or personal telemetric profiles.
  • Local In-Memory & Device Storage: All scores, player rankings, queue entries, and match histories exist purely in local device session storage.
  • No Third-Party Cookies: No behavioral advertising or ad trackers are loaded.
  • AI Rulebook & Match Commentary: Questions asked to the AI referee are anonymized and sent solely for dispute resolution, with offline local rule fallback.
