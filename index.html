USA Pickleball Rules & Quick Ref

Rule 4.B - Starting Server (0-0-2)

At the start of each doubles game, the starting serving team only receives ONE serve turn before side-out. Hence, the starting server is designated Server 2.

Rule 9.B - Non-Volley Zone (The Kitchen)

A player cannot volley the ball while touching any part of the non-volley zone or kitchen line.
